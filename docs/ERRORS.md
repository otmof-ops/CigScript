# Error codes

Every diagnostic `cig` prints carries a stable code, rendered as `error[E502 runtime]: ...`, and every code is a node in one registry (`errors/registry.toml`): its family, which of the **four kinds of no** it is ([the lexicon](LEXICON.md#the-four-kinds-of-no)), what it means, what to type next, and its ranked causes, each with the read-only probe doctor uses to confirm it and the remedy. `cig explain <code>` prints the same page at the terminal; `cig explain --schema` prints the JSON Schema that `--json` output follows ([diagnostic.schema.json](diagnostic.schema.json)).

A code never changes meaning. A retired code is never reused. A code marked *planned* is reserved for a feature that has not shipped. Generated by `scripts/gen-errors-doc.py`; do not edit by hand.

## Ranges

| codes | family | rendered as | meaning |
|---|---|---|---|
| `E100`–`E199` | lex | `lex` | lexing: the source cannot be turned into tokens |
| `E200`–`E299` | syntax | `syntax` | parsing: the tokens do not follow the grammar |
| `E300`–`E399` | check | `check` | static check (`cig check`): a mistake found before anything runs |
| `E400`–`E499` | type | `type` | types and arity: a value of the wrong shape reached an operation |
| `E500`–`E519` | runtime | `runtime` | runtime: a failure while the script was running, including the resource ceilings |
| `E520`–`E529` | ghost | `runtime` | the ghost filesystem: dry-run reads of paths that simulated ops changed |
| `E550`–`E569` | hop | `runtime` | hops (process boundaries): child processes and foreign scripts |
| `E600`–`E699` | cough | `cough` | raised by the script: cough, assert, chains, process checks |
| `E700`–`E749` | kernel | `burn` | the burn kernel and its journal (write-ahead log) |
| `E750`–`E769` | fold | `burn` | folds and packs: refusals when automation is composed |
| `E800`–`E849` | usage | `usage` | the command line and the environment |
| `E850`–`E869` | update | `usage` | the updater and doctor |
| `E900`–`E999` | internal | `internal` | internal: a bug in CigScript itself |

## The four kinds of no

| id | what you hear | whose problem | the manual's name |
|---|---|---|---|
| `none` | not one of the four | a mistake in the text, in the arithmetic, or in CigScript | syntax, type or logic error; an internal error |
| `cant-see-any` | can't see any ciggies bro | yours: you're pointed at the wrong place | wrong address: a path, a name, a directory not on PATH; ENOENT |
| `these-are-mine` | these are MY ciggies | the door: it knows you and said no | 403 Forbidden; permission denied; a lock; a refusal by policy |
| `dont-have-any` | don't have any over here | nobody's: right place, right you, nothing there | 404 from the server's side; an empty result |
| `depends` | one of the four; the message says which | read the operating-system reason in the message | ENOENT, EACCES, ENOSPC and friends, each mapped in the causes below |

## lex (`E100`–`E199`)

lexing: the source cannot be turned into tokens.

| code | title | kind of no | what to type next |
|---|---|---|---|
| [`E100`](#e100-lexing-error) | lexing error | not one of the four | fix the character or literal the message names; `cig language` shows the forms |
| [`E101`](#e101-unterminated-string) | unterminated string | not one of the four | close the string on the same line, or write \n for a newline inside it |
| [`E102`](#e102-unknown-escape) | unknown escape | not one of the four | use \n \t \r \0 \\ \" \$ \u{hex}; for a regex or a Windows path use a raw 'single-quoted' string |
| [`E103`](#e103-unexpected-character) | unexpected character | not one of the four | spell logic as `and`, `or`, `not`; comparisons are == != < <= > >= |
| [`E104`](#e104-malformed-number) | malformed number | not one of the four | use a float (add .0) for magnitudes beyond 9223372036854775807; -9223372036854775808 is valid with the minus directly in front |

### E100 lexing error

*lex · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

The source contains something the lexer cannot turn into tokens.

**What to type next:** fix the character or literal the message names; `cig language` shows the forms

**Known causes**, ranked; doctor checks them in this order:

1. a character or literal the lexer does not know (probe `source-line`). **Remedy:** fix it at the caret


### E101 unterminated string

*lex · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A string literal has no closing quote on its line.

**What to type next:** close the string on the same line, or write \n for a newline inside it

**Known causes**, ranked; doctor checks them in this order:

1. the closing quote is missing, or sits on the next line (probe `string-literal-scan`). **Remedy:** close the string on the line it opened; use \n for a line break inside it
2. an escaped quote \" swallowed the closing quote (probe `source-line`). **Remedy:** count the backslashes before the last quote; a raw 'single-quoted' string has no escapes


### E102 unknown escape

*lex · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A backslash sequence in a double-quoted string is not one CigScript knows.

**What to type next:** use \n \t \r \0 \\ \" \$ \u{hex}; for a regex or a Windows path use a raw 'single-quoted' string

**Known causes**, ranked; doctor checks them in this order:

1. a Windows path or a regex inside a double-quoted string (probe `source-line`). **Remedy:** write it as a raw 'single-quoted' string, which has no escapes at all
2. a typo in an escape (no probe; a suggestion, not a finding). **Remedy:** the escapes are \n \t \r \0 \\ \" \$ and \u{hex}


### E103 unexpected character

*lex · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A character cannot start any token, often a C-style operator.

**What to type next:** spell logic as `and`, `or`, `not`; comparisons are == != < <= > >=

**Known causes**, ranked; doctor checks them in this order:

1. a C-style operator: && || ! (probe `source-line`). **Remedy:** spell them `and`, `or`, `not`
2. a smart quote or a non-breaking space pasted from a document; the message shows the character (probe `source-line`). **Remedy:** retype the character with a plain quote or space


### E104 malformed number

*lex · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A numeric literal does not fit in 64 bits or is not well formed.

**What to type next:** use a float (add .0) for magnitudes beyond 9223372036854775807; -9223372036854775808 is valid with the minus directly in front

**Known causes**, ranked; doctor checks them in this order:

1. the literal is larger than 9223372036854775807 (probe `int-magnitude`). **Remedy:** add .0 to make it a float, or check whether the number is right
2. a stray character inside the number (probe `source-line`). **Remedy:** digits and single underscores only: 1_000_000

Related: `E503`.

| [`E207`](#e207-empty-chain) | empty chain | not one of the four | list the sticks (steps) to light: chain name { fetch, build } |

### E200 syntax error

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

The source does not follow the grammar.

**What to type next:** look at the caret; the message says what was expected; `cig language` shows the forms

**Known causes**, ranked; doctor checks them in this order:

1. parsing stopped at the caret, short of what was expected (probe `source-line`). **Remedy:** supply what was expected, or remove what was not


### E201 expected an expression

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A value was expected here and something else was found.

**What to type next:** complete the expression; look for a trailing operator or comma

**Known causes**, ranked; doctor checks them in this order:

1. a trailing operator or comma with nothing after it (probe `source-line`). **Remedy:** finish the expression, or delete the operator
2. a keyword used where a value should be (probe `source-line`). **Remedy:** keywords are fine as map keys and member names, not as values


### E202 unclosed block

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A `{` has no matching `}`.

**What to type next:** add the closing brace where the block ends

**Known causes**, ranked; doctor checks them in this order:

1. a block opened and never closed (probe `brace-balance`). **Remedy:** add `}` at the end of that block


### E203 expected end of statement

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

Two statements share a line without a separator.

**What to type next:** put each statement on its own line, or separate them with `;`

**Known causes**, ranked; doctor checks them in this order:

1. two statements on one line (probe `source-line`). **Remedy:** put each statement on its own line, or separate them with `;`


### E204 not a statement

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A word that is not a keyword starts the line, usually a typo.

**What to type next:** use the spelling the hint suggests; `cig language` lists the keywords

**Known causes**, ranked; doctor checks them in this order:

1. a typo in a keyword (probe `similar-names`). **Remedy:** use the suggestion in the hint
2. a word from another language: let, var, const, def, function (no probe; a suggestion, not a finding). **Remedy:** `roll` for a variable, `stick` for a constant, `pull` for a function, `pack` for a lambda


### E205 invalid assignment target

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

The left side of `=` is not something that can hold a value.

**What to type next:** assign to a name, `list[i]` or `map.key`

**Known causes**, ranked; doctor checks them in this order:

1. assigning to a call result or a literal (probe `source-line`). **Remedy:** assign to a name, `list[i]` or `map.key`
2. `=` where `==` was meant, inside a condition (probe `source-line`). **Remedy:** write `==` to compare


### E206 chained comparison

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

Comparisons cannot be chained like `a < b < c`.

**What to type next:** write `a < b and b < c`

**Known causes**, ranked; doctor checks them in this order:

1. `a < b < c` read as one expression (probe `source-line`). **Remedy:** write `a < b and b < c`


### E207 empty chain

*syntax · since 1.0.0 · arises in parse*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A chain declares no steps.

**What to type next:** list the sticks (steps) to light: chain name { fetch, build }

**Known causes**, ranked; doctor checks them in this order:

1. `chain name { }` with nothing inside (probe `source-line`). **Remedy:** put the steps inside, one per line or comma-separated

### E300 check error

*check · since 1.0.0 · arises in check*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

The static checker found a mistake before running anything.

**What to type next:** read the message; `cig check` shows all of them at once

**Known causes**, ranked; doctor checks them in this order:

1. the checker found the mistake at the line shown (probe `source-line`). **Remedy:** fix it there; `cig check <file>` lists every one


### E301 unknown name

*check · since 1.0.0 · arises in check*

**Kind of no:** can't see any ciggies bro (yours: you're pointed at the wrong place; wrong address: a path, a name, a directory not on PATH; ENOENT).

A name is used that was never declared in a visible scope.

**What to type next:** use the name the hint suggests, or declare it with `roll` or `stick` above this line

**Known causes**, ranked; doctor checks them in this order:

1. a typo in the name (probe `similar-names`). **Remedy:** use the suggested name
2. the name is declared later in the file, or inside another block (no probe; a suggestion, not a finding). **Remedy:** move the declaration above the first use, or out of the inner block
3. a module function called without its module: read_text instead of fs.read_text (probe `similar-names`). **Remedy:** prefix it with the module; `cig language` lists them

Related: `E307`, `E501`.


### E302 stick reassigned

*check · since 1.0.0 · arises in check*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

A `stick` is a constant and cannot be assigned again.

**What to type next:** declare it with `roll` if it needs to change

**Known causes**, ranked; doctor checks them in this order:

1. a stick (constant binding) assigned a second time (probe `source-line`). **Remedy:** declare it with `roll`; a stick is a promise that it will not change

Related: `E507`.


### E303 effect outside burn

*check · since 1.0.0 · arises in check*

**Kind of no:** these are MY ciggies (the door: it knows you and said no; 403 Forbidden; permission denied; a lock; a refusal by policy).

A function that changes the world is called where no `burn` block encloses it.

**What to type next:** wrap the call in burn { ... }; inside a pull this is a warning, since the caller may burn

**Known causes**, ranked; doctor checks them in this order:

1. a world-changing call at the top level with no burn { } around it (probe `source-line`). **Remedy:** wrap the call in burn { ... }, or the call to the function that makes it
2. inside a pull or pack: a warning, because the caller may burn (no probe; a suggestion, not a finding). **Remedy:** nothing, if every caller burns; wrap it if the function should work from anywhere

Related: `E701`.


### E304 snuff outside a function

*check · since 1.0.0 · arises in check*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

`snuff` returns from a pull or pack and was used at the top level.

**What to type next:** use exit(code) to stop the script

**Known causes**, ranked; doctor checks them in this order:

1. `snuff` (return) at the top level of the script (probe `source-line`). **Remedy:** use exit(code), or move the code into a pull


### E305 break outside a loop

*check · since 1.0.0 · arises in check*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

`break` or `continue` appears outside `while` or `for`.

**What to type next:** move it inside the loop, or restructure with `if`

**Known causes**, ranked; doctor checks them in this order:

1. `break` or `continue` outside `while` or `for` (probe `source-line`). **Remedy:** move it inside the loop, or restructure with `if`


### E306 already declared

*check · since 1.0.0 · arises in check*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A name is declared twice in the same scope.

**What to type next:** assign with `name = ...` the second time, or choose another name

**Known causes**, ranked; doctor checks them in this order:

1. `roll x` twice in one scope (probe `source-line`). **Remedy:** write `x = ...` the second time


### E307 unknown module member

*check · since 1.0.0 · arises in check*

**Kind of no:** can't see any ciggies bro (yours: you're pointed at the wrong place; wrong address: a path, a name, a directory not on PATH; ENOENT).

A module such as `fs` has no function by that name.

**What to type next:** use the member the hint suggests; `cig language` lists every one

**Known causes**, ranked; doctor checks them in this order:

1. a typo in the member: fs.read_txt (probe `similar-names`). **Remedy:** use the suggestion in the hint
2. a function from another language's library (no probe; a suggestion, not a finding). **Remedy:** `cig language` shows what exists; text.*, fs.* and path.* cover most needs

Related: `E301`.


### E308 shell through proc.run

*check · since 1.1.0 · arises in check*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

proc.run is handed a shell (`sh -c`, `bash -c`, `cmd /C`) with a command string built at run time; that is where every injection bug in every glue script has lived.

**What to type next:** call the program directly with its arguments as a list; proc.pipe for a pipeline; proc.shell if you mean the shell and the string is yours

**Known causes**, ranked; doctor checks them in this order:

1. a value that came from outside the script is spliced into a shell command (probe `source-line`). **Remedy:** pass the value as its own argument to the program; the shell never sees it


## type (`E400`–`E499`)

types and arity: a value of the wrong shape reached an operation.

| code | title | kind of no | what to type next |
|---|---|---|---|
| [`E400`](#e400-type-error) | type error | not one of the four | convert with str(), int() or float(), or test with type_of() |
| [`E401`](#e401-wrong-number-of-arguments) | wrong number of arguments | not one of the four | match the signature; packs have no optional parameters, pass null explicitly |
| [`E402`](#e402-wrong-argument-type) | wrong argument type | not one of the four | convert the value first: str(n), int(s), or path.join for paths |
| [`E403`](#e403-operator-not-applicable) | operator not applicable | not one of the four | strings join with +, numbers add; convert first with str() or int() |
| [`E404`](#e404-not-callable) | not callable | not one of the four | only packs, pulls and library functions can be called |
| [`E405`](#e405-not-indexable-or-iterable) | not indexable or iterable | not one of the four | lists, strings and maps support [] and for; check type_of() |

### E400 type error

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A value of the wrong type reached an operation.

**What to type next:** convert with str(), int() or float(), or test with type_of()

**Known causes**, ranked; doctor checks them in this order:

1. a value of the type the message names (probe `value-types`). **Remedy:** convert the value first, or branch on type_of()


### E401 wrong number of arguments

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A call passes more or fewer arguments than the function takes.

**What to type next:** match the signature; packs have no optional parameters, pass null explicitly

**Known causes**, ranked; doctor checks them in this order:

1. the call passes more or fewer arguments than the pack or pull declares (probe `source-line`). **Remedy:** match the declaration; pass null for an argument you do not have
2. a method called on the wrong receiver, so the receiver counted as an argument (no probe; a suggestion, not a finding). **Remedy:** check what the dot is applied to


### E402 wrong argument type

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

A library function received an argument of the wrong type.

**What to type next:** convert the value first: str(n), int(s), or path.join for paths

**Known causes**, ranked; doctor checks them in this order:

1. an argument of the wrong type, at the position the message names (probe `value-types`). **Remedy:** convert the value first: str(n), int(s), float(s)


### E403 operator not applicable

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

An operator was applied to types it does not support.

**What to type next:** strings join with +, numbers add; convert first with str() or int()

**Known causes**, ranked; doctor checks them in this order:

1. a string plus a number (probe `value-types`). **Remedy:** interpolate: "count: ${n}", or str(n) + "..."
2. arithmetic on null from a missing key or a ?. chain (probe `value-types`). **Remedy:** give it a default: x ?? 0


### E404 not callable

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

Something that is not a function was called.

**What to type next:** only packs, pulls and library functions can be called

**Known causes**, ranked; doctor checks them in this order:

1. a name that holds a value, not a function, followed by () (probe `value-types`). **Remedy:** drop the parentheses, or call the function you meant
2. a module called as a function: fs() (probe `source-line`). **Remedy:** call a member: fs.read_text(...)


### E405 not indexable or iterable

*type · since 1.0.0 · arises in run*

**Kind of no:** not one of the four (a mistake in the text, in the arithmetic, or in CigScript; syntax, type or logic error; an internal error).

Indexing or iteration was attempted on an unsupported type.

**What to type next:** lists, strings and maps support [] and for; check type_of()

**Known causes**, ranked; doctor checks them in this order:

1. indexing or looping over null, a number or a bool (probe `value-types`). **Remedy:** check type_of(x); a missing key or an empty glob is the usual source of the null


## runtime (`E500`–`E519`)

runtime: a failure while the script was running, including the resource ceilings.

| code | title | kind of no | what to type next |
|---|---|---|---|
| [`E500`](#e500-runtime-error) | runtime error | not one of the four | read the message; wrap risky code in try/ashtray to handle it |
| [`E501`](#e501-unknown-name-at-run-time) | unknown name at run time | can't see any ciggies bro | run `cig check`; it finds this before anything runs |
| [`E502`](#e502-division-by-zero) | division by zero | not one of the four | guard the divisor: if d != 0 { ... } |
| [`E503`](#e503-integer-overflow) | integer overflow | not one of the four | use floats (1.0 * n) for very large magnitudes, or check bounds first |
| [`E504`](#e504-index-out-of-range) | index out of range | can't see any ciggies bro | check .len() first, or use .get(i, default); [-1] is the last item |
| [`E505`](#e505-missing-key) | missing key | don't have any over here | use m?.key for null, or m.get("key", default) |
| [`E506`](#e506-call-depth-exceeded) | call depth exceeded | not one of the four | add the base case first; rewrite as a loop if depth may legitimately exceed 4,000 |
| [`E507`](#e507-stick-reassigned-at-run-time) | stick reassigned at run time | these are MY ciggies | run `cig check`, then declare the binding with `roll` if it must change |
| [`E508`](#e508-file-system-failure) | file system failure | one of the four; the message says which | check the path with fs.exists first; relative paths resolve against the working directory `cig runs <id>` shows |
| [`E509`](#e509-process-failure-(retired)) | process failure (retired) | one of the four; the message says which | read E551, E552 and E554; the hop rules are in docs/HOPS.md |

# Error codes

Every diagnostic `cig` prints carries a stable code, rendered as `error[E502 runtime]: ...`. `cig explain <code>` prints the entry below at the terminal; `--json` output carries the code in a `code` field. Generated by `scripts/gen-errors-doc.py`; do not edit by hand.

The first digit is the layer that produced the error:

- Lexing (E1xx)
- Parsing (E2xx)
- Static check (E3xx)
- Types and arity (E4xx)
- Runtime (E5xx)
- Raised by the script (E6xx)
- The burn kernel (E7xx)
- Command line and environment (E8xx)
- Internal (E9xx)


## Lexing (E1xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E100` | lexing error | The source contains something the lexer cannot turn into tokens. | Read the message; it names the character or literal. |
| `E101` | unterminated string | A string literal has no closing quote on its line. | Close the string, or use \n for a newline inside it. |
| `E102` | unknown escape | A backslash sequence in a double-quoted string is not one CigScript knows. | Use \n \t \r \0 \\ \" \$ \u{hex}; for regexes use a raw 'single-quoted' string. |
| `E103` | unexpected character | A character cannot start any token, often a C-style operator. | Spell logic as `and`, `or`, `not`; comparisons as == != < <= > >=. |
| `E104` | malformed number | A numeric literal does not fit in 64 bits or is not well formed. | Use a float for very large values, or fix the literal. |

## Parsing (E2xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E200` | syntax error | The source does not follow the grammar. | The caret marks where parsing stopped; `cig language` shows the forms. |
| `E201` | expected an expression | A value was expected here and something else was found. | Complete the expression; check for a stray operator or comma. |
| `E202` | unclosed block | A `{` has no matching `}`. | Add the closing brace; each block opener needs one. |
| `E203` | expected end of statement | Two statements share a line without a separator. | Put each statement on its own line or separate them with `;`. |
| `E204` | not a statement | A word that is not a keyword starts the line, usually a typo. | Check the spelling against the hint; `cig language` lists the keywords. |
| `E205` | invalid assignment target | The left side of `=` is not something that can hold a value. | Assign to a name, `list[i]` or `map.key`. |
| `E206` | chained comparison | Comparisons cannot be chained like `a < b < c`. | Write `a < b and b < c`. |
| `E207` | empty chain | A chain declares no steps. | List the sticks to light: chain name { fetch, build }. |

## Static check (E3xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E300` | check error | The static checker found a mistake before running anything. | Read the message; run `cig check` to see all of them. |
| `E301` | unknown name | A name is used that was never declared in a visible scope. | Declare it with `roll` or `stick`, or fix the spelling (see the hint). |
| `E302` | stick reassigned | A `stick` is a constant and cannot be assigned again. | Declare it with `roll` if it needs to change. |
| `E303` | effect outside burn | A function that changes the world is called where no `burn` block encloses it. | Wrap the call: burn { ... }. Inside a pull this is a warning, since the caller may burn. |
| `E304` | snuff outside a function | `snuff` returns from a pull or pack and was used at the top level. | Use exit(code) to stop the script. |
| `E305` | break outside a loop | `break` or `continue` appears outside `while` or `for`. | Move it inside the loop, or restructure with `if`. |
| `E306` | already declared | A name is declared twice in the same scope. | Assign with `name = ...`, or choose another name. |
| `E307` | unknown module member | A module such as `fs` has no function by that name. | See the hint, or `cig language` for the full list. |

## Types and arity (E4xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E400` | type error | A value of the wrong type reached an operation. | Convert with str(), int(), float(), or check type_of(). |
| `E401` | wrong number of arguments | A call passes more or fewer arguments than the function takes. | Check the signature; CigScript has no optional parameters for packs. |
| `E402` | wrong argument type | A library function received an argument of the wrong type. | The message names the argument and the expected type. |
| `E403` | operator not applicable | An operator was applied to types it does not support. | Strings join with +, numbers add; convert first with str() or int(). |
| `E404` | not callable | Something that is not a function was called. | Only packs, pulls and library functions can be called. |
| `E405` | not indexable or iterable | Indexing or iteration was attempted on an unsupported type. | Lists, strings and maps support this; check type_of(). |

## Runtime (E5xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E500` | runtime error | Something failed while the script was running. | The message says what; wrap risky code in try/ashtray to handle it. |
| `E501` | unknown name at run time | A name was looked up that is not in scope. | Usually only reachable with --no-check; run `cig check`. |
| `E502` | division by zero | An integer or float was divided by zero, or the modulus was zero. | Guard the divisor: if d != 0 { ... }. |
| `E503` | integer overflow | An integer operation left the 64-bit range. | Use floats for very large magnitudes. |
| `E504` | index out of range | A list or string index is outside its length. | Check .len() first, or use .get(i, default). |
| `E505` | missing key | A map has no entry for the key that was read. | Use m?.key for null, or m.get("key", default). |
| `E506` | call depth exceeded | Recursion went deeper than 4,000 calls. | Add a base case, or rewrite as a loop. |
| `E507` | stick reassigned at run time | A constant was assigned through a path the checker could not see. | Declare it with `roll` if it needs to change. |
| `E508` | file system failure | A file or directory operation failed. | The message shows the path and the operating-system reason. |
| `E509` | process failure | A program could not be started, or exceeded its timeout and was killed. | Check it is installed (proc.which), or raise {timeout_ms}. |
| `E510` | invalid regular expression | A pattern passed to the text module does not compile. | Use a raw 'single-quoted' string and check the pattern. |
| `E511` | parse failure | Text that should be JSON or CSV is not. | Validate the input; the message includes the parser's reason. |
| `E512` | range too large | A range or list construction would exceed 10,000,000 items. | Iterate in smaller pieces. |
| `E513` | output closed | The reader of stdout went away (for example `| head`). | Nothing to fix; the script stopped cleanly. |

## Raised by the script (E6xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E600` | raised by the script | The script called `cough` and nothing caught it. | Catch it with try/ashtray, or let it stop the run; burns are rolled back. |
| `E601` | assertion failed | assert() was given a false value. | The optional second argument becomes the message. |
| `E602` | chain failed | A step of a chain raised an error and the chain stopped. | The error map carries chain, step, index and cause; or light with {continue_on_error: true}. |
| `E603` | process check failed | proc.run with {check: true} saw a non-zero exit code. | The error map holds code, out and err. |

## The burn kernel (E7xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E700` | burn refused | The kernel refused a side effect. | Read the message; effects need a burn block. |
| `E701` | effect outside burn | A world-changing call ran with no burn block active on the call stack. | Wrap the call, or the call to the function that makes it, in burn { }. |
| `E702` | journal failure | The kernel could not record a burn before performing it, so it refused it. | Check disk space and permissions under ~/.cigscript (or CIGSCRIPT_HOME). |

## Command line and environment (E8xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E800` | usage error | The command line or the environment is wrong. | See `cig --help`. |
| `E801` | cannot read script | The script file could not be opened. | Check the path and permissions. |
| `E802` | state directory unavailable | The state directory cannot be created or written. | Set CIGSCRIPT_HOME to a writable location. |
| `E803` | no such run | No run record matches the id or prefix given. | `cig runs` lists them; give more of the id if it is ambiguous. |
| `E804` | no such chain | The script declares no chain by that name. | `cig chains <file>` lists them. |
| `E805` | network tool missing | Neither `gh` nor `curl` is available for the update or report. | Install one of them; `cig doctor --fix` offers to. |
| `E806` | update failed | The release could not be fetched, verified or installed. | The message says which step; retry, or install manually from the releases page. |

## Internal (E9xx)

| code | title | meaning | fix |
|---|---|---|---|
| `E900` | internal error | CigScript hit a condition it believes impossible. | Please report it: `cig crash send` after the crash, or file an issue. |
| `E901` | crash | CigScript panicked. A crash report was written locally. | Run `cig crash list` and `cig crash send <id>` to file it, or say yes at the prompt. |
